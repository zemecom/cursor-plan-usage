# AGENTS.md — cursor-plan-usage

Локальное расширение Cursor. Источник поведения — `extension.js`, `session.js`, `usage.js`, `dashboard.js` и `package.json`. Репозиторий: `https://github.com/zemecom/cursor-plan-usage`.

## 1. Стек и запуск

- CommonJS, без `npm` и без сборки. Хост — процесс расширений Cursor (`engines.vscode` в `package.json`). `extensionKind` равен `ui`: в удалённом окне расширение остаётся на локальной машине, где лежат база и связка ключей.
- Код выполняется на хосте, не в Docker. Сессия читается через `/usr/bin/sqlite3` из `state.vscdb` в режиме `mode=ro`. Значение `cursor-safe-storage:v1:` на macOS расшифровывается ключом связки `Cursor Safe Storage` до любого запроса. После отказа в доступе к связке повторный диалог появляется только по явному обновлению: команда, кнопка дашборда, клик по периоду или повторное открытие панели.
- Установка: симлинк `~/.cursor/extensions/zemecom.cursor-plan-usage` на корень этого репозитория. Имя каталога без суффикса версии. `publisher` в `package.json` — `zemecom` (полный id расширения `zemecom.cursor-plan-usage`).
- После правки кода подними `version` в `package.json` и то же значение у `zemecom.cursor-plan-usage` в `~/.cursor/extensions/extensions.json`. Cursor следит за `extensions.json`: запись ключуется идентификатором и версией. Смена версии в профиле заставляет заново прочитать расширение с диска. Если версия в `package.json` отличается от уже загруженной хостом, в карточке появляется Restart Extensions. Хост сам не перезапускай.

## 2. Инварианты

- В статусбаре тариф и значки той же записью `$(…)`, что и левый `$(pulse)`: `$(plan-grok)` для Grok (`autoPercentUsed`), `$(symbol-misc)` для Other (`apiPercentUsed`), `$(credit-card)` для OD. Значок Grok — свой, через `contributes.icons` и файл `media/grok.ttf` (не `.woff`: загрузчик Cursor отдаёт `.ttf` вне корня папки расширений, а ярлык установки раскрывается в реальный путь). Проценты в строке — с одним знаком после запятой, без знака `%`. Слова Grok, Other и OD остаются в подсказке и на карточках. На карточке дашборда вместо слова Grok — тот же контур как SVG. OD (`spendLimitUsage`) показывать только при расходе больше нуля. `totalPercentUsed` в интерфейс не выводить.
- Статусбар: `StatusBarAlignment.Left` и `Number.MIN_SAFE_INTEGER`, чтобы строка стояла у правого края левой группы.
- Токен, cookie и почту не писать в репозиторий, логи и ответы. В базе только `SELECT`. В интерфейс попадают короткие коды (`keychain`, `http-401`, `bad-response`), не текст ответа и не команда `sqlite3`. События без своей почты не показывать, если в ответе почта есть.
- Один проход обновления читает сессию и снимок тарифа по одному разу. Сводка моделей с `api2.cursor.sh` запрашивается только когда список событий не загрузился. Пустой успешно загруженный период оставляет таблицу моделей пустой.
- Таймер не опрашивает окно без фокуса и не тянет события для скрытой панели. Скрытая панель обновляется, когда её снова показывают. Смена периода во время уже идущего запроса ставит ещё один проход, а не теряется.
- Запросы к `cursor.com` для списка событий ограничивать дедлайном. Если список загружен целиком, дни без событий остаются на графике с нулём, не длиннее 62 дней. Обрезанный список остаётся разреженным.
- Слушатель сообщений webview регистрировать до присвоения `webview.html`.

## 3. Проверка

Перед сдачей правки:

```bash
node --check extension.js && node --check session.js && node --check settings.js && node --check usage.js && node --check usage-model.js && node --check dashboard.js && node --test
```

`node --test` гоняет чистые функции из `usage-model.js`. Поведение панели проверяется в открытом дашборде Cursor.
