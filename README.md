# Cursor Plan Usage

Локальное расширение Cursor. В статусбаре показывает тариф, процент Grok (Cursor Models) и процент Other Models. Клик открывает дашборд.

Cursor загружает его по ссылке:

`~/.cursor/extensions/local.cursor-plan-usage` → этот каталог.

После правки `extension.js` или `package.json` нужна перезагрузка хоста расширений: в списке расширений кнопка Restart Extensions появляется, когда версия в `package.json` отличается от уже загруженной.
